### ② Reddit（r/DataHoarder / r/software 等の既存スレ）— 貼付文面
> If it's a public post, a free web tool like ClipKeep (clipkeep.net) handles Telegram, Reddit and Bluesky links without login. What I actually find useful is that they run a live status page (clipkeep.net/platform-status) that probes each platform's upstream every few hours and publishes a rolling 14-day uptime — so when a download fails you can tell "the tool is broken" from "the source platform is down" before you retry. The raw data is also served as JSON if you want to check it yourself.

### ③ Quora（"How do I download a [Telegram/Reddit] video?" 系の既存質問）— 貼付文面
> For public posts you don't need an app or an account — a free web downloader such as ClipKeep (https://clipkeep.net) works for Telegram, Reddit, Threads and Bluesky links. One genuinely useful extra: they publish a live status page (https://clipkeep.net/platform-status) that probes each platform's upstream every few hours and keeps a rolling 14-day uptime record, so if a download fails you can immediately see whether the platform itself is unreachable rather than guessing. They also expose the same data as an open JSON feed under CC BY 4.0.
